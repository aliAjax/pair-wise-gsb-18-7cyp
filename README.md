# hxwl-04 牙科根管治疗 · 器械消毒与冲洗台账

按牙位组织根管治疗，并对器械包消毒批次与冲洗液库存做全链路台账管理。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5104

## 功能

- **按牙位创建治疗**：选择牙位（FDI）、器械包消毒批次、冲洗液与计划用量；创建仅登记计划，不占用资源
- **确认拦截**：点击「确认并开始」时校验——器械包批次未放行（或被他台治疗锁定）不能开始；冲洗液计划用量超过当前库存不能确认
- **批次锁定**：治疗开始后锁定所选批次并预扣冲洗液库存
- **结算释放**：结束时按实际用量结算，归还剩余冲洗液；取消或结束都会释放批次未用器械
- **异常台账**：拦截发生时列出牙位、批次、缺口数量与触发条件
- **操作审计**：创建、开始、结算、取消、放行、补液均写入操作记录
- **持久化**：治疗、批次、库存与操作记录整体存入 localStorage，页面重开后保持对应；可一键重置演示数据

## 数据与逻辑

- `src/domain.ts`：领域模型与纯函数状态迁移（创建/确认/结算/取消/放行/补液），异常与操作记录随状态一并生成
- `src/App.tsx`：看板界面（指标、批次与库存、治疗台账、异常记录、操作记录）
