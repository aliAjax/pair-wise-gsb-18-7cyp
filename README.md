# hxwl-04 根管治疗 · 器械消毒与冲洗台账

按牙位组织根管治疗，绑定器械包消毒批次与冲洗液用量，形成可追溯的消毒与冲洗台账。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5104

## 功能

- 按牙位创建治疗：选择器械包（批次）、冲洗液与用量（mL）
- 双重拦截：器械包批次未放行、冲洗液用量超过当前库存时均不能确认开始
- 生命周期：创建（待确认）→ 确认开始（锁定批次、预扣冲洗液）→ 完成 / 取消
- 结束或取消时释放未用器械包，并归还剩余冲洗液（完成时可登记实际用量）
- 器械包批次放行 / 退回待放行，冲洗液入库补充
- 异常清单：列出牙位、批次、缺口数量与触发条件
- 操作记录：创建、开始、完成、取消、入库、放行、拦截全程留痕
- localStorage 持久化：重开页面后治疗、批次、库存与操作记录保持对应
